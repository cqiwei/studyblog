## 为什么是静态站

1 核 1G 的机器跑 WordPress 会很紧张，但跑一个静态站几乎不占资源——Nginx 发文件，内存占用常年几十兆。

所以这条路线是：

- 本地用 Hugo 把 Markdown 编译成 HTML
- 上传到服务器的 `releases/` 目录
- 用一个软链接指向当前版本，切换即生效、回滚即改链接

## 第一次部署

```bash
# 服务器上只需要装 nginx，不需要 php、不需要数据库
sudo apt install -y nginx
```

写完文章，本地执行 `deploy.ps1`，几十秒后线上就能看到。

> 静态站的好处是：没有数据库要备份，没有插件要升级，被打了也打不出洞——它只会发文件。
