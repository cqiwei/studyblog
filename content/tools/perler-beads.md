拼豆（Perler / Hama beads）的乐趣一半在拼，一半在「到底要买多少豆」。这个小工具帮你把两件事一起解决：上传图片 → 自动量化成 MARD 色号 → 输出带网格的图纸和用量清单。

### 怎么用

1. 选一张主体清晰、背景干净的图（二次元头像、宠物、logo 效果最好）。
2. 拖宽度滑块：**30 格**适合小挂件，**50 格**是一块标准大板，**80 格以上**适合照片级细节。
3. 看下面的用量清单，按色号去配豆子，缺哪个买哪个。

### 几个参数

- **最多用色**：限制色板数量。16~24 色是大多数图案的甜点区，颜色越少越好买、越好拼。
- **去噪点**：把孤立的单颗豆子并进周围颜色，省豆子也省眼睛。照片建议 2 级。
- **抖动**：适合照片，靠交错排布模拟更多层次；做卡通/像素风时关掉更干净。
- **去纯白背景**：自动把接近纯白的格子留空，拼的时候不用铺满整板。

### 关于色板

色号来自 [MARD 拼豆](https://github.com/Jett-Wu/Perler_Beads_Generator) 的 291 色板（基础 221 色 + 扩展 70 色），也是国内最容易买到的体系。同样的图换成别的品牌颜色会略有偏差，但编号逻辑通用。

### 说明

图片全部在浏览器本地处理，不会上传到任何服务器；关掉页面就什么都不剩。这个工具参考了 GitHub 上几个开源项目的思路（[Perler_Beads_Generator](https://github.com/Jett-Wu/Perler_Beads_Generator)、[perler-pattern](https://github.com/sucpyy/perler-pattern)，均为 MIT），配色算法是自己重写的简化版。
